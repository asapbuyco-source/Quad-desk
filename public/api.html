◆ QUANT DESK

API

Recorded derivatives data over HTTPS. The same endpoints that power the terminal.

Private beta. Keys are issued manually while we finalise rate limits and licensing. Email support@quantdeskterminal.com with your use case.

Base URL

https://quantdeskterminal.com/api

All requests require an X-API-Key header. Responses are JSON and include an as_of timestamp and a source field where applicable.

curl -H "X-API-Key: YOUR_KEY" \
  "https://quantdeskterminal.com/api/funding-history?symbol=BTCUSDT&limit=42"

Endpoints

EndpointReturns
/healthService status. No key required.
/funding-history?symbol=&limit=8h funding settlements, accumulated %, annualised.
/positioning?symbol=&period=&limit=Retail L/S, top traders, top positions, taker flow.
/liquidations?symbol=&minutes=&limit=Forced orders, price clusters, 24h hourly heat.
/rsi-screener?universe=RSI(14) on 15m/1h/4h for liquid perps.
/whales?limit=Top Hyperliquid accounts and open positions.
/funding-heatmap?limit=Funding extremes across perps.
/premium?symbol=Coinbase spot vs Binance reference premium.
/macro, /fxFRED series and ECB reference rates.
