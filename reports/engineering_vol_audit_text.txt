The current system has no suchfilter and will enter long positions triggered by ignition events, taking the exact adverse fill the manipulator intends. This is the singlehighest-expected-cost defect in the spoofing domain.

STRUCTURAL JITTER DEFECT J-01: 15-SECOND POLLING LOOP
The bot's core decision cycle runs every 15 seconds regardless of market state. On a 15-minute candle system, this yields 60 evaluationopportunities per candle  but most are idle, wasting computational cycles without providing sub-candle alpha. The candle_close_event.set()provides one event-driven trigger per candle close, which is the correct primary entry trigger. However, mid-candle signal changes (e.g., a liquiditysweep at candle T+7min) are evaluated at the next 15s tick boundary, introducing up to 14.9s of signal latency for intrabar events.Recommendation: implement adaptive polling  fast polling (2s) in TREND/LIQUIDITY regimes, slow polling (30s) in confirmed RANGE. Thispreserves CPU budget while reducing sweep latency.

STRUCTURAL JITTER DEFECT J-02: SL/TP PLACEMENT IS SEQUENTIAL
After market order fill, the bot places SL then TP in separate sequential REST calls, each with asyncio.sleep(1.0) between attempts. Total SL+TPplacement time: 200ms2s under normal conditions, 310s if the first SL attempt fails and falls back to STOP_MARKET. During this window theposition is unprotected. Recommendation: submit OCO (One-Cancels-Other) order on Binance USDM using the native OCO endpoint  atomicSL/TP in a single API call. CCXT supports this via create_order with 'TAKE_PROFIT' and 'STOP_MARKET' in a single request payload.
STRUCTURAL JITTER DEFECT J-03: TP REQUEUE DELAY UP TO 60 SECONDS
Failed TP placements are requeued via attempt_tp_requeue() which is polled by the heartbeat at approximately 60-second intervals. A failed TPmeans the position holds no profit-lock for up to 60 seconds. In high-volatility BTC moves, 60 seconds can represent 38 ATR candles.Resolution: move TP requeue to the main analysis loop at every 15s tick, not the heartbeat.
